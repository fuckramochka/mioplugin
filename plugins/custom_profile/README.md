# Custom Profile ✦

**ID**: `custom_profile`  
**Версія**: `1.8.1`  
**Автор**: @RoflPlugins & @fuckramochka  
**Категорія**: Customization

## 📝 Опис
Розширене оформлення та кастомізація профілю Telegram: кольорові градієнти, кастомні банери, стилі бульбашок повідомлень.

## 🚀 Встановлення
1. Завантажте `plugin.py` або `manifest.json`.
2. Відкрийте в **Miogram** -> **Налаштування** -> **Плагіни** -> **Додати плагін**.
