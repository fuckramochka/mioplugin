# Message Styler ✦

**ID**: `message_styler`  
**Версія**: `1.0.0`  
**Автор**: @fuckramochka  
**Категорія**: Formatting

## 📝 Опис
Форматування та стилізація вихідних повідомлень (естетичні шрифти, декоративні символи, автоматичне застосування Markdown).

## 🚀 Встановлення
1. Завантажте `plugin.py` або `manifest.json`.
2. Відкрийте в **Miogram** -> **Налаштування** -> **Плагіни** -> **Додати плагін**.
