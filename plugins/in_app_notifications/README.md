# In-App Notifications ✦

**ID**: `in_app_notifications`  
**Версія**: `1.0.0`  
**Автор**: @fuckramochka  
**Категорія**: UI / UX

## 📝 Опис
Елегантні спливаючі внутрішні сповіщення під час перебування в додатку із швидкою відповіддю та плавними анімаціями.

## 🚀 Встановлення
1. Завантажте `plugin.py` або `manifest.json`.
2. Відкрийте в **Miogram** -> **Налаштування** -> **Плагіни** -> **Додати плагін**.
