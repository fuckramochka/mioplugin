# Dice Roller

Tabletop dice for chats. The roll is expanded to plain text before sending,
so it works everywhere with no bot needed.

- `.roll 2d6` — two six-sided dice
- `.roll d20` — single d20
- `.roll 4d6dl1` — four d6, drop the lowest one
- `.flip` — coin flip

Limits: max 20 dice, max 1000 sides.
