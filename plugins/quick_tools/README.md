# Quick Tools ✦

**ID**: `quick_tools`  
**Версія**: `1.0.0`  
**Автор**: @fuckramochka  
**Категорія**: Utility

## 📝 Опис
Корисні інструменти у контекстних меню повідомлень: копіювання ID користувача/каналу, копіювання чистого тексту без форматування, швидкий переклад.

## 🚀 Встановлення
1. Завантажте `plugin.py` або `manifest.json`.
2. Відкрийте в **Miogram** -> **Налаштування** -> **Плагіни** -> **Додати плагін**.
